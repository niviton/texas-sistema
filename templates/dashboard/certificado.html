Certificado do Polaris para o celular

O celular só libera o GPS (para o carimbo de local nas fotos) em sites seguros. Instale este certificado uma vez em cada celular: o aviso de "site não seguro" some e o Polaris passa a pedir a localização.

{% if tem_certificado %} Baixar certificado do Polaris

Arquivo polaris-ca.crt. Ele vale só para o Polaris da rede da oficina.

{% else %}

O certificado ainda não foi gerado neste computador. O administrador deve rodar python manage.py certificado_local.

{% endif %}

Android

  1. Toque em Baixar certificado do Polaris.
  2. Abra Configurações → Segurança (ou "Segurança e privacidade") → Mais configurações de segurança → Criptografia e credenciais → Instalar um certificado → Certificado de CA.
  3. Toque em Instalar mesmo assim, confirme com a senha do celular e escolha o arquivo polaris-ca.crt em Downloads.
  4. Feche e abra o Chrome de novo e entre no Polaris pelo endereço com https://.

iPhone

  1. Abra esta página no Safari e toque em Baixar certificado do Polaris; toque em Permitir.
  2. Abra Ajustes → Perfil baixado → Instalar e confirme.
  3. Abra Ajustes → Geral → Sobre → Ajustes de Confiança de Certificados e ative Polaris - rede local.
  4. Entre no Polaris pelo endereço com https://.

Sem instalar

Também dá para entrar sem instalar: no aviso de site não seguro, toque em Avançado → Continuar para o site. Em alguns celulares, porém, o GPS continua bloqueado assim; por isso a instalação é o caminho recomendado.
